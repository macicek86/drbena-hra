# Game Brief: Drběna sbírá drby (Kopidlno)

## Základní info
- **Název hry:** Drběna sbírá drby
- **Žánr:** 2D side-scroller sběrač s překážkami
- **Cílová platforma:** Web (HTML5), ideálně i mobilní ovládání
- **Styl:** Cartoon, barevný, veselý, hezký od začátku
- **Délka kola:** 1–3 minuty

## Postava
**Drběna** – roztomilá koza-maskot Kopidlenské Drbny.
- Černo-bílá (levá strana bílá, pravá černá)
- Růžová mašle s žlutým knoflíkem
- Velké expresivní oči, rohy
- Vzhled podle dodaných referencí (front + side views)

## Herní mechanika
- Drběna běží zleva doprava po Kopidlně / zámeckém parku.
- Hráč ovládá **skok** (mezerník / tap) a případně **úhyb**.
- Sbírá „drby“ (bubliny / poznámky / body).
- Překážky: ploty, zahradníci, psi, větve, auta, květináče apod.
- Po sebrání většího počtu drbů se zobrazí krátký fun fact o Kopidlně.
- Highscore + možnost sdílení.

## Lokace (reference)
- Náměstí
- Zámek Kopidlno
- Palmový skleník
- Zámecký park / rybník

## Podklady od klienta
- Front view Drběny (dodáno)
- Side views + základní pozice (generováno)
- Fotky lokací (klient připraví)

## Požadavek na vývoj
Hezký cartoon styl, snadné ovládání, plynulá animace Drběny, responzivní webová hra.
